# 四个顶层页统一页头（AppPageHeader）

- 日期：2026-11-19
- 状态：生效中
- 来源：随会话统计顶层化（见 [2026-11-19-usage-stats-top-level-tab.md](2026-11-19-usage-stats-top-level-tab.md)）派生

## 结论

四个顶层页（配置与分发/模型配置/历史会话/会话统计）的页头统一为一份共享组件
`@shared/ui/AppPageHeader.vue`：左侧 h2 标题加一句数据口径描述，右侧控件组（默认插槽），
两组底边对齐、窄窗整组换行。吸顶外壳、页面留白与底部分隔线仍归各页自己——组件只管一行内的结构。

各页标题即左栏条目名；描述写数据口径，不罗列右侧可见控件：

| 页面 | 描述 |
| --- | --- |
| 配置与分发 | 把 Skills 与 MCP 分发到各工具的全局与项目 target |
| 模型配置 | 集中管理聚合提供商的模型配置并一键应用到各工具 |
| 历史会话 | 读取各 AI 编码工具本地目录中的会话记录 |
| 会话统计 | 按会话内消耗事件的实际时间归日统计 |

## 关键取舍

- **第三次重复时抽组件**：会话统计、历史会话先后落了同一段页头结构与标题排版，配置与分发、
  模型配置再各抄一份就是四处漂移的副本；shared/ui 只收纯展示件（AppCard 同例），不承载业务
  类型，四个域各自往插槽里放自己的控件，不产生跨域样式依赖。
- **页签归入右侧控件组**：配置与分发与模型配置的 tab 导航从页头左侧移到右侧控件组，四个页
  头从同一起点（左标题、右控件）长出来；tab 内容与行为不变。
- **页签为文字下划线式**：参考「工作区/提交历史」样式——未选中灰色文字，选中态墨色加粗 +
  2px 主色下划线，下划线盖在 header 分隔线上融为一体。实现靠 nav 的 `-13px` 底 margin
  抵消各 header 的 12px 底 padding 再多盖 1px——header 底 padding 改动时这个值要跟着改。
  中途试过 chip 描边底与 switch 滑块两个变体，均按反馈回退到本方案。
- **会话搜索框的横向拉伸保留**：共享页头的控件组默认靠右收拢，需要拉伸的控件在插槽里自行
  flex-grow（`.sessions-filter` 即是）。
- **随 tab 切换的页面动作不进页头**：配置与分发三个面板 Teleport 到
  `#workspace-panel-actions` 的动作（新增 Target/来源/MCP、skills 搜索框）挂在页头下方，
  与同行的标题说明组成面板区块头，页头只留页面级结构（标题、描述、页签）。区块头形态与
  模型配置页的「聚合提供商」区块一致：左侧标题 + 一句说明，右侧动作按钮。
- **每个页头都带底部分隔线**：五个顶层页（配置与分发/模型配置/历史会话/会话统计/关于）的
  页头一律有底部分隔线（吸顶页的分隔线随吸顶条固定）；此前只有前两页有，后三页补齐。
  非吸顶页用 `--color-hairline-soft`，吸顶页（模型配置/会话统计）用 `--color-hairline`。
